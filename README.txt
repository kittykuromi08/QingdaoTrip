QINGDAO TRIP WEBSITE
====================
파일:
- index.html : 홈페이지
- style.css  : 디자인
- script.js  : DAY 필터 / 체크리스트 / 메모 저장

GitHub Pages:
1. GitHub에서 새 repository를 만든다. 예: qingdao-trip
2. 이 폴더 안의 3개 파일(index.html, style.css, script.js)을 업로드한다.
3. Settings → Pages → Deploy from a branch → main / root 선택 → Save
4. 잠시 기다리면 https://내아이디.github.io/qingdao-trip/ 형태로 공개된다.

참고:
현재 홈페이지의 일정은 제공해주신 Excel 스프레드시트의 현재 내용을 기준으로 만들었습니다.
